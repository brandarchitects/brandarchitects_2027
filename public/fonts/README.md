# Schriften

Markenschrift der Website: **Archivo Variable** (Omnibus-Type, SIL Open Font License 1.1). Dateien und Lizenz liegen in
`app/fonts/` und werden in `app/[locale]/layout.tsx` über `next/font/local` eingebunden – nie über Google-Fonts-URLs.
Beide Achsen (Gewicht 100–900, Breite 62–125) in einer Datei; die Breite steuert die typografische Handschrift (docs/design-spec.md).

Dieser Ordner bleibt leer, bis eine kommerziell lizenzierte Schrift an ihre Stelle tritt (Entscheid Pascal, docs/design-spec.md Kap. 2).
